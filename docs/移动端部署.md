# 把雪乃搬到手机上陪你聊天

## 0. 先明确一件事：什么必须留在有显卡的机器上

| 组件 | 硬件需求 | 能不能搬到手机 |
|---|---|---|
| GPT-SoVITS 语音合成 | **GPU 约 1.5~3.5 GB 显存**（CPU 也能跑但 1 句要十几秒） | ❌ 不能 |
| 本地大模型（qwen2:7b） | **GPU 约 4.5 GB 显存**（CPU 也能跑，约 3~8 tok/s） | ❌ 不能 |
| Web 服务 `app/server.py` | 几乎零资源 | 可以，但没必要 |
| SQLite 好感度/记忆 | 零资源 | 可以，但没必要 |

**结论：脑（LLM）和嗓子（TTS）都吃显卡，手机端只当「遥控器 + 显示器」。**
所以正确做法是「电脑/服务器当后端，手机浏览器当客户端」，而不是把模型塞进手机。

好消息是你现在的 `app/server.py` 已经是**纯标准库、零依赖、响应式、可装成 PWA** 的形态，
只要让手机能访问到它的地址就行。

---

## 1. 四种方案速选

| 方案 | 适用场景 | 成本 | HTTPS | 难度 | 需要公网 IP |
|---|---|---|---|---|---|
| **A. 同一 Wi-Fi 直连** | 在家用，最快验证 | 0 | ❌ | ⭐ | 否 |
| **B. Tailscale 组网**（推荐） | 出门也想用，电脑留在家 | 0 | ✅（serve 模式） | ⭐⭐ | 否 |
| **C. Cloudflare Tunnel** | 想给别人用 / 长期稳定在线 | 0 | ✅ 自动 | ⭐⭐⭐ | 否 |
| **D. 真·云服务器** | 24 小时在线、不依赖家里电脑 | 按小时计费（GPU 贵） | ✅ | ⭐⭐⭐⭐ | 是 |

## 2. 方案 A：同一 Wi-Fi（5 分钟，今天就试）

### 电脑端

```powershell
cd D:\Yukino

# 1) 启动后端（两个窗口）
ollama serve
.\scripts\start_tts.ps1

# 2) 启动手机可访问的 Web 服务（会打印手机地址 + 令牌）
.\scripts\start_mobile.ps1
```

输出类似：

```
=== 手机访问地址 ===
  http://192.168.1.23:8501/?t=a8Kd2mQx9p

  提示：手机与电脑要在同一个 Wi-Fi
```

### 手机端

1. 连上**同一个 Wi-Fi**（注意别连 5G 热点而电脑走有线不同网段）
2. 浏览器打开上面那条地址（**必须带 `?t=令牌`**，第一次打开后会自动种 cookie，之后不用带了）
3. 想当 App 用：
   - **iOS Safari**：分享 → 添加到主屏幕
   - **Android Chrome**：菜单 → 安装应用 / 添加到主屏幕

### 打不开的话依次排查

| 现象 | 处理 |
|---|---|
| 手机完全连不上 | 首次访问时 Windows 会弹防火墙询问 → 选「专用网络」允许。或管理员运行 `.\scripts\start_mobile.ps1 -OpenFirewall` |
| 能 ping 通但打不开端口 | 电脑网络配置成「公用网络」时防火墙默认拦。把网络改成「专用」 |
| 手机连的是访客 Wi-Fi | 很多路由器开启 **AP 隔离**，设备之间不能互通。换成主 Wi-Fi |
| 地址打错 | 电脑上 `ipconfig` 看 IPv4 地址，确认是 `192.168.x.x` / `10.x.x.x` |

> 方案 A 没有 HTTPS。除了「不能装 PWA」「以后不能用麦克风」以外，日常聊天没问题。

## 3. 方案 B：Tailscale（推荐，出门也能用）

原理：给电脑和手机组一个私有虚拟局域网（100.x.x.x），**不需要公网 IP、不用在路由器上开端口**，
流量端到端加密，比把 8501 暴露到公网安全得多。

### 步骤

1. 电脑和手机都装 [Tailscale](https://tailscale.com/download)，登录**同一个账号**
2. 电脑上查自己的 Tailscale IP：
   ```powershell
   tailscale ip -4
   # 输出类似 100.101.102.103
   ```
3. 启动雪乃（**这时可以只绑 127.0.0.1**，因为 Tailscale 会转发）：
   ```powershell
   cd D:\Yukino
   python -m app.server --host 127.0.0.1 --port 8501 --token 你的令牌
   ```
4. 手机上打开：
   ```
   http://100.101.102.103:8501/?t=你的令牌
   ```
   或者直接用 Tailscale 的 MagicDNS 名称：`http://你的电脑名:8501/?t=...`

### 进阶：要 HTTPS（想装 PWA / 以后用麦克风）

Tailscale 自带证书转发，一条命令即可：

```powershell
# 先确认已开启 HTTPS 证书功能（管理后台 Settings → Keys → HTTPS Certificates）
tailscale serve --bg 8501
# 会给出形如 https://你的电脑名.xxxx.ts.net 的地址
```

然后把 `app.server` 绑回 `127.0.0.1` 即可（`tailscale serve` 负责对外）。

## 4. 方案 C：Cloudflare Tunnel（有域名，长期在线）

适合「希望任何时候都能打开，不依赖家里电脑是否开机」或者「要分享给朋友」。
免费额度足够个人用，且**自动给 HTTPS**（PWA 和麦克风必需）。

### 快速试（临时地址，重启会变）

```powershell
winget install --id Cloudflare.cloudflared
cloudflared tunnel --url http://127.0.0.1:8501
# 输出形如 https://random-words.trycloudflare.com
```

手机打开：`https://random-words.trycloudflare.com/?t=你的令牌`

### 正式部署（固定域名）

```powershell
cloudflared tunnel login
cloudflared tunnel create yukino
cloudflared tunnel route dns yukino yukino.你的域名.com
cloudflared tunnel run --url http://127.0.0.1:8501 yukino
```

建议在 Cloudflare 后台加 **Access 策略**（邮箱白名单），否则等于对公网开放你的显卡。

## 5. 方案 D：迁到真正的云服务器

### 现实提醒

- **TTS 必须 GPU**。云 GPU（T4 / A10）按小时计费，长期跑不便宜。
- 7B 模型的 CPU 推理只有 3~8 tok/s，端到端会到 20~60 秒，体验差。
- 所以「纯 CPU 云服务器」只适合跑 Web + 调用云端 LLM API（`LLM_PROVIDER=deepseek`），
  语音仍建议留在家里那台 4060 上。

### 迁移清单

```powershell
# 1) 代码（仓库只有 15.7 MB，模型不在里面）
git clone https://github.com/Yukino-love-oos/yukino_web.git
cd yukino_web

# 2) .env
Copy-Item .env.example .env
# 按服务器情况改：
#   LLM_PROVIDER=deepseek 或 ollama
#   OLLAMA_HOST=http://127.0.0.1:11434
#   GSV_API_BASE=http://127.0.0.1:9880   ← 若 TTS 在另一台机器，填那台的地址
#   YUKINO_TOKEN=一个强口令

# 3) 模型权重（不在 git 里，需要单独上传 ~400 MB）
#    yukino/Yukino/GPT_weights/{default.ckpt, Yukino_Weak-e25.ckpt}   约 296 MB
#    yukino/Yukino/SoVITS_weights/Yukino_{Strong,Weak_01,Weak_02}.pth  约 243 MB
#    yukino/Yukino/参考音频/001.*.wav                                 约 0.6 MB
#    以及 GPT-SoVITS 整合包本体（~22 GB，从官方 Release 下载）

# 4) 启动
python -m app.server --host 0.0.0.0 --port 8501 --token 强口令
```

### 拆分架构（省钱又保体验）

```
        ┌──────────────────────────┐
 手机 ──►│ 云服务器(无 GPU，便宜)     │
        │  app/server.py           │
        │  LLM = DeepSeek API      │
        └───────────┬──────────────┘
                    │ Tailscale 内网
        ┌───────────▼──────────────┐
        │ 家里 4060 电脑             │
        │  GPT-SoVITS :9880        │
        └──────────────────────────┘
```

服务器 `.env` 里只改一行：

```dotenv
LLM_PROVIDER=deepseek
DEEPSEEK_API_KEY=sk-你的新key
GSV_API_BASE=http://家里的tailscale-IP:9880
```

家里那台仍然用 `.\scripts\start_tts.ps1` 起 TTS 即可（它绑 `127.0.0.1`，
需要改成 `0.0.0.0` 才能被外部访问：`runtime\python.exe api_v2.py -a 0.0.0.0 -p 9880 -c ...`）。

## 6. 手机上的体验要点

| 事项 | 说明 |
|---|---|
| **音频解锁** | iOS/Android 禁止自动播放。页面已实现「点『送信』时解锁 AudioContext」，**第一句话必须有这个点击动作**才算数 |
| **添加到主屏幕** | 非 HTTPS 下 iOS 只能加书签，不能全屏运行；要真·App 感需要 HTTPS（方案 B 的 `tailscale serve` 或方案 C） |
| **切后台会断** | 浏览器在锁屏/切后台时暂停音频，回来点一下继续 |
| **流量** | 每句语音是 32 kHz 单声道 wav 转 base64，约 100~200 KB；纯文字几乎没有流量 |
| **省电** | 真正耗电的是后端显卡，不是手机；人在外面时电脑要保持开机 |
| **横竖屏** | 已做响应式：≤820px 宽自动变成「顶部小立绘 + 下方对话」单列，输入框 16px 避免 iOS 自动放大 |

## 7. 安全清单（对外暴露前务必逐条确认）

1. **一定要设 `--token`**（或 `YUKINO_TOKEN`）。不设令牌 + `--host 0.0.0.0` = 同一网络任何人都能用你的显卡。
2. **优先用 Tailscale / Cloudflare Access**，而不是在路由器上做端口映射（port forwarding）。
3. 防火墙规则只勾「专用网络」，不要把 8501 暴露给公用网络。
4. `.env` 里有 API Key，**不要提交**；`.gitignore` 已排除。
5. 之前泄露的 DeepSeek Key（`sk-4672…`）**必须已在控制台吊销**，源码与新 Git 历史里都已清除。
6. 想更稳：在反向代理（Caddy/Nginx）上做限流，或给 `app/server.py` 加每 IP 每分钟请求数上限。

## 8. 常见问题

**Q：手机打开了但一直「连接中…」**
A：`/api/state` 被拦了。检查地址是否带 `?t=令牌`；或把 `YUKINO_TOKEN` 清空重启试（仅限内网）。

**Q：有字没声音**
A：① TTS 没起（`.\scripts\start_tts.ps1`）② iOS 需要点击「送信」触发解锁 ③ 检查电脑上 `http://127.0.0.1:9880/docs` 是否 200。

**Q：一句要等二三十秒**
A：本地 7B 在 8 GB 显存 + TTS 常驻时只有 8 tok/s（见 README 实测）。换 `qwen2.5:3b-instruct` 或把 `OLLAMA_KEEP_ALIVE=0` 会好很多。

**Q：以后想用语音输入（说话而不是打字）**
A：需要两件事：① HTTPS（`getUserMedia` 要求安全上下文）② 装 `faster-whisper` + `silero-vad`。这两步还没做，是下一个阶段。
