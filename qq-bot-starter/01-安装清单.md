# 01 · 安装清单（照着打勾）

> 预计：文字私聊 1～2 小时（含下载）。语音/表情包另算。
> 每一步都有「做到什么算过」，没过就别急着下一步。

---

## 第 0 步 · 备份（5 分钟）

- [ ] 关掉 DSH 桌面版
- [ ] 运行 `04-备份与回滚/backup-dsh.ps1`
  ```powershell
  powershell -ExecutionPolicy Bypass -File "D:\Yukino\qq-bot-starter\04-备份与回滚\backup-dsh.ps1"
  ```
- [ ] 看到 `备份完成` 和 zip 路径（默认在 `D:\Yukino\tmp\dsh-backups\`）

**过没过**：zip 文件存在且 > 1 KB。

---

## 第 1 步 · 准备 QQ 号（10 分钟）

- [ ] 决定机器人用哪个 QQ（建议小号，且能在这台电脑扫码登录）
- [ ] 手机 QQ 上把主号加为机器人号好友（后面配对要用）

**过没过**：机器人号能正常登录 QQ。

---

## 第 2 步 · 下载 NapCat（10 分钟）

下载页：<https://github.com/NapNeko/NapCatQQ/releases>

| 你现在的 QQ 情况 | 下载哪个 |
|---|---|
| 想沿用本机已装的 QQ 9.9.36（`D:\tencent\QQ.exe`） | `NapCat.Shell.zip` |
| 想让它自带一套独立 QQ | `NapCat.Shell.Windows.OneKey.zip` |

- [ ] 下载完成（约 100～300 MB，视版本）
- [ ] 如果 GitHub 打不开/很慢，在链接前加加速前缀再试，例如：
  `https://ghfast.top/https://github.com/NapNeko/NapCatQQ/releases/download/<版本>/NapCat.Shell.zip`
  （前缀换 `https://gh-proxy.com/` 也可以；还不行就找社区镜像）
- [ ] 解压到 **`D:\NapCat`**（路径不要带空格、不要放桌面、不要放 C 盘用户目录）

**过没过**：`D:\NapCat\launcher.bat` 存在。

---

## 第 3 步 · 启动 NapCat 并登录（10 分钟）

- [ ] 双击 `D:\NapCat\launcher.bat`
- [ ] 控制台选择登录方式 → 手机 QQ **扫码**
- [ ] 登录成功后，控制台会打印 WebUI 地址和 token；把 token 抄到记事本
- [ ] 浏览器打开 `http://127.0.0.1:6099/webui`（token 在网址参数里，或看 `D:\NapCat\config\webui.json`）

**过没过**：WebUI 能打开，首页能看到机器人 QQ 号和在线状态。

---

## 第 4 步 · 开 OneBot 正向 WebSocket（5 分钟）

NapCat WebUI → 网络配置 → 新建 → **WebSocket 服务器**

- [ ] 填：

| 字段 | 填 |
|---|---|
| 名称 | `dafeiyu-ws` |
| 主机 | `127.0.0.1` |
| 端口 | `13001` |
| Token | 自己编一串随机字符（例如 `yukino-8f3k2`），记下来 |
| 消息格式 | `array` |
| 启用 | 开 |

- [ ] 保存，确认列表里显示已启用

**过没过**：列表里这条是「启用」状态，NapCat 窗口没关。

---

## 第 5 步 · 装「大肥鱼」插件（10 分钟）

插件仓库：<https://github.com/wz20/dsh-dafeiyu-dot>

**方式一（推荐）**：DSH 侧栏 → 插件市场/插件管理 → 安装 → 粘贴
`https://github.com/wz20/dsh-dafeiyu-dot` → 确认 → 启用 → 重启 DSH。

**方式二**：先退出 DSH 桌面版，再在 PowerShell 里跑：

```powershell
& "E:\DSH\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add "https://github.com/wz20/dsh-dafeiyu-dot" --ignore-scripts
```

- [ ] 安装成功，重启 DSH
- [ ] 侧栏出现「大肥鱼」

**没成功时**：
- 报接口不兼容 → 到 DSH 设置里检查更新（你的版本是 0.2.0-rc.2，插件基线 0.2.1-rc.3）
- 报网络错误 → GitHub 访问问题，挂代理或用加速后再装
- 报端口/文件占用 → 先完全退出 DSH 再装

---

## 第 6 步 · 插件里连 QQ（15 分钟）

打开「大肥鱼」配置中心，按顺序：

- [ ] **角色**：先填名字和称呼（提示词先用 `02-人格/核心人设-模板.md`，跑通再精修）
- [ ] **会话**：新建一个专用会话（叫「QQ 陪伴」），选它作为陪伴会话，打开陪伴模式
- [ ] **QQ**：
  - WebSocket 地址 `ws://127.0.0.1:13001`
  - Token：第 4 步那串
  - NapCat 管理地址 `http://127.0.0.1:6099`（插件默认是 16099，**一定要改**）
  - WebUI Token：第 3 步抄的
  - 保存 → 「重新连接」→ 状态变「已连接」
- [ ] **配对**：主号 QQ 私聊机器人号，按提示完成配对

**过没过**：QQ 私聊发 `你好`，几秒内有回复。

---

## 第 7 步 · 群聊（可选，5 分钟）

- [ ] 把机器人号拉进群
- [ ] 插件「群」设置里**逐个群启用**
- [ ] 群里 @机器人 说句话

**过没过**：只有 @ 时回，不 @ 不乱说话。

---

## 第 8 步 · 记忆（可选，5 分钟）

- [ ] 插件「记忆」页打开陪伴记忆
- [ ] 私聊说「记住：我每天 23 点睡」
- [ ] 重启 DSH，再问「我几点睡」

**过没过**：能答出来。答不出就检查记忆开关和陪伴会话是否选对。

---

## 第 9 步 · 语音（可选，可跳过，最容易翻车）

- [ ] 先跳过。等文字、群、记忆都稳定后再弄。
- [ ] 到时候在「语音」页选「OpenAI 兼容 API」，填一个支持 `POST /v1/audio/speech` 的服务
- [ ] 本机已有 GPT-SoVITS（Yukino 项目），但需要包一层 OpenAI 兼容接口才能被插件调用

---

## 第 10 步 · 稳定性（10 分钟）

- [ ] 改 `03-启动与自启/start-qq-bot.bat` 开头的 4 个变量
- [ ] 双击测试能一键拉起
- [ ] 运行 `03-启动与自启/注册开机自启.ps1`
- [ ] 重启电脑验证一次

**过没过**：重启后不做任何操作，QQ 私聊能收到回复。

---

## 附 · 全流程大概长这样

```
备份 → QQ 号 → NapCat 解压 → 扫码登录 → 开 WS:13001
   → DSH 装插件 → 配置中心：角色/会话 → 连 QQ / 配对
   → 群里 @ 测试 → 记忆测试 → （可选）语音 → 开机自启
```
