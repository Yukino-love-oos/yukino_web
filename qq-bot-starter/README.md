# QQ 陪伴机器人 · 配套文件包

配合 [`docs/QQ陪伴机器人-搭建指南.md`](../docs/QQ陪伴机器人-搭建指南.md) 使用。

```
qq-bot-starter/
├─ 01-安装清单.md            ← 按顺序打勾，照着点
├─ 02-人格/                  ← 复制粘贴进插件「角色」页
│   ├─ 核心人设-模板.md
│   ├─ 核心人设-示例-雪乃.md
│   ├─ 主人附加规矩.md
│   ├─ 她自己的可变层-self-rules.md
│   ├─ 群聊模式人格.md
│   └─ 群画像/示例群.json
├─ 03-启动与自启/
│   ├─ start-qq-bot.bat
│   ├─ stop-qq-bot.bat
│   └─ 注册开机自启.ps1
├─ 04-备份与回滚/
│   ├─ backup-dsh.ps1
│   └─ restore-dsh.ps1
└─ 05-素材/stickers/         ← 自定义表情包目录模板
```

## 使用顺序

1. **先备份**（`04-备份与回滚/backup-dsh.ps1`）—— 别跳过。
2. 照 `01-安装清单.md` 装 NapCat → 开 OneBot WS → 装大肥鱼插件。
3. 把 `02-人格/` 里的内容填进插件角色页（先用模板，跑通再精修）。
4. 装好之后按 `03-启动与自启/` 配置一键启动，确认能稳定掉线重连。
5. 想要自定义表情，再动 `05-素材/stickers/`。

## 三个必须改的地方

| 文件 | 要改什么 |
|---|---|
| `03-启动与自启/start-qq-bot.bat` | 开头 4 个变量：NapCat 目录、机器人 QQ 号、DSH exe 路径 |
| `03-启动与自启/注册开机自启.ps1` | 一般不用改（自动定位第 1 步那个 bat）；换位置时改 `$Bat` |
| `02-人格/*.md` | 名字、称呼、底线 |
