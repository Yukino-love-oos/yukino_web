# 自定义表情包（贴纸）说明

插件自带 10 张主题贴纸。想换成自己的图，按下面做。

## 目录位置

```
C:\Users\PC\.dsh\dsh-dafeiyu-dot\assets\stickers\
├─ catalog.json      ← 索引（格式见本目录的 catalog.json）
├─ nod.png
├─ hmm.png
├─ smug.png
├─ tired.png
├─ pout.png
└─ pat.png
```

> 具体目录以插件配置页/文档为准；插件数据根目录是
> `C:\Users\PC\.dsh\dsh-dafeiyu-dot\`。

## 做法

1. 把本目录的 `catalog.json` 复制过去（先删掉里面的 `_说明` 字段）。
2. 准备 6 张图，按 `file` 字段命名（`nod.png`、`hmm.png`…）。
3. 每张图建议：**正方形、240～480 px、PNG、体积 < 500 KB**，透明背景更好看。
4. 改 `catalog.json` 里的 `title`（提示名）和 `tags`（命中词），让模型知道什么时候用。
5. 重启 DSH 或重连插件后生效。

## 字段含义

| 字段 | 作用 |
|---|---|
| `id` | 唯一标识，英文小写，别重复 |
| `title` | 给人看/给模型看的名字 |
| `emotion` | 情绪分类，决定什么心情下发（calm/joyful/concerned/playful/angry/sad/sleepy/warm/apologetic/surprised） |
| `tags` | 触发词，模型按这些词判断该不该发 |
| `file` | 图片文件名，必须和实际文件一致 |
| `mime` | 固定 `image/png`；用 jpg 就写 `image/jpeg` 并改扩展名 |

## 调频率

表情发太多会很烦。在人格提示词里写死：

```text
情绪到位才发表情，平均 5～8 条消息才发一张，不要每条都配图。
```

发太少了？把 `tags` 写得更日常一点（比如加上「嗯」「好」「笑」），
或者把上面那句改成 3～5 条一张。

## 图从哪来

- 自己截/画的图、朋友授权给你的图；
- 网上找的图注意版权，别用于商业或公开传播；
- **不要在群里发带真人脸、带别人隐私的图**——机器人账号会被举报。
